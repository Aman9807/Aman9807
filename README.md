### 🚀 Highlighted Engineering Projects

#### 💻 Software & SaaS Systems
* **SchoolOS** 
  > A robust Windows desktop application for school management built with **Flutter**. Engineered with a strict **offline-first architecture**—data is stored locally for zero-latency performance and automatically syncs to **Cloudflare R2** on a 1-to-2 hour interval and upon application closure. Includes automated API key generation for seamless school website integration.
* **Faimily Medical System** 
  > A comprehensive medical billing and inventory management system featuring payment gateway integrations and custom, localized UPI QR code generation.
* **Cricdeck (`cricdeck.flynx.site`)** 
  > A live broadcasting web application tailored for local cricket tournaments. It provides real-time score tracking and seamless **OBS Studio** integration to generate professional live scoreboard overlays.
* **The Flynx Web Ecosystem** 
  > Designed and deployed a suite of web tools including [`flynx.site`](https://flynx.site) (main portal), `taabit` (digital invitation creator), and `reelfetch` (social media video utility).
