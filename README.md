### 👨‍💻 About Me & My Focus

I am a student developer with a strong passion for building end-to-end systems. From soldering microcontrollers to designing local-first software architectures and exploring LLM fine-tuning, I enjoy the entire spectrum of technology.

- 🏗️ **Architecture Philosophy:** I specialize in **offline-first** and local-first application designs, ensuring software remains functional without continuous internet access while handling background cloud synchronization.
- 🔭 **Currently Building:** A fully-featured, voice-and-face-recognizing AI assistant (Jarvis-style) utilizing structured long-term memory.
- 🌱 **Learning Roadmap:** Advancing my skills in Python, Machine Learning (ML), Deep Learning (DL), and diving into the mechanics of building and fine-tuning custom LLMs.

### 🚀 Highlighted Engineering Projects

#### 💻 Software & SaaS Systems
* **SchoolOS** 
  > A robust Windows desktop application for school management built with **Flutter**. Engineered with a strict **offline-first architecture**—data is stored locally for zero-latency performance and automatically syncs to **Cloudflare R2** on a 1-to-2 hour interval and upon application closure. Features include AI integrations and automated API key generation for seamless school website integration.
* **Faimily Medical System** 
  > A comprehensive medical billing and inventory management system featuring payment gateway integrations and custom, localized UPI QR code generation.
* **Cricdeck (`cricdeck.flynx.site`)** 
  > A live broadcasting web application tailored for local cricket tournaments. It provides real-time score tracking and seamless **OBS Studio** integration to generate professional live scoreboard overlays.
* **The Flynx Web Ecosystem** 
  > Designed and deployed a suite of web tools including [`flynx.site`](https://flynx.site) (main portal), `taabit` (digital invitation creator), and `reelfetch` (social media video utility).

#### 🤖 Hardware & Autonomous Robotics
* **Vision-Based Autonomous Car:** Utilized an ESP32-CAM module to process real-time images for autonomous navigation.
* **Obstacle Avoidance Robotics:** Engineered a rover utilizing ultrasonic sensors for spatial awareness and pathfinding.
* **Precision Line-Follower:** Designed and calibrated a closed-loop control system for a high-speed line-following robot.
