- 🏗️ **Architecture Philosophy:** I specialize in **offline-first** application designs, ensuring software remains functional without continuous internet access while handling background cloud synchronization.
- 🔭 **Currently Building:** A fully-featured, voice-and-face-recognizing AI assistant (Jarvis-style) utilizing structured long-term memory.
- 🌱 **Learning Roadmap:** Advancing my skills in Python, Machine Learning (ML), Deep Learning (DL), and diving into the mechanics of custom LLMs.
